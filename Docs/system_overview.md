# Dalax Biobot System Overview

## Subsystems
- **UnityClient**: Visualizes DNA sequences, mutates biobots, and simulates behavior.
- **QuantumEngine**: Encodes DNA into quantum circuits for advanced mutation modeling.
- **BlockchainIntegration**: Registers unique DNA sequences onto the Ethereum blockchain.
- **Docker**: Containers for Flask API, middleware, and future CI/CD pipelines.

## Flow
1. Unity sends DNA to Flask API for quantum processing.
2. Flask encodes to quantum circuit.
3. Middleware registers DNA hash to blockchain.
4. Unity visualizes results in a simulation environment.
